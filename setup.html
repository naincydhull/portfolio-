Ek baar ka setup

Supabase me site_content table banani hai — bas 3 step. Uske baad admin panel ka warning hamesha ke liye chala jayega.

1

Supabase SQL Editor kholen

Neeche wale button se SQL Editor khulega — SQL pehle se bhara hua hoga.

Supabase SQL Editor kholen
2

Run dabayen

SQL Editor me Run (ya Ctrl+Enter) dabayen. Success message aayega.

3

Admin panel wapas kholein

Warning hat jayegi aur saari website information save hone lagegi.

Admin panel kholein
!

Agar admin me 403 / "Permission denied" aaye

Ye chota SQL sirf permissions theek karta hai. Kholein, Run dabayen, phir admin.html reload karein. Kuch delete nahi hota.

403 fix SQL kholein
