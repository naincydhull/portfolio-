Naincy Portfolio
================
Files:
  index.html  - the portfolio website
  admin.html  - the admin panel (open it as  your-site/admin.html )

How to put it online:
  1. Unzip this folder first (GitHub's web upload does not unzip files for you).
  2. Upload index.html and admin.html to the ROOT of your GitHub repo
     (Add file > Upload files > Commit changes).
  3. On vercel.com: Add New > Project > import the repo > Deploy.
  4. Open your-site/admin.html, log in, and press
     "Import current website projects" once.

Never put your Supabase secret key or any password inside these files.
